## What is measured

Not a method: g is fitted per layer *with the targets of fit* (J++'s softplus surrogate of "best target above the
10th competitor", over a candidate vocabulary; Adam, 150 steps, small L2), then scored exactly (full vocabulary, the
bench's item rule over every read cell and grid layer, cos readout). Classes: `ceil.const` (one vector per layer),
`ceil.tok` (one per read token with >= 3 cells, else a shared one), `ceil.clu` (one per kmx64 cluster), `ceil.proj16`
(a learned mean plus a learned rank-16 subspace removed). Three reads: **in-sample** (fit and score on all fit items),
**3-fold by group** (fit on two folds, score the third: the honest ceiling of the class, i.e. how much a perfectly
tuned g of that class could transfer to new items of the same family), **val** (fit on all of fit, read val).
Baselines `zero` and `fam (logo)` through the same scorer, on the same scored items.

Caveats, written before the run:
- The surrogate's optimum is a *lower bound* on the true in-sample ceiling of a class (local optimum, a smooth
  surrogate of a per-cell rule while the item rule takes the best cell and layer).
- On the `_mt` families the scorer counts an item as passing when any required unit's piece is in the top 10 (the
  union of required ids), looser than the piece proxy's all-units rule: compare ceilings with `zero` / `fam` in the
  same table, never with `out/eval` numbers.
- Per-family fits: a const ceiling here is "the best fixed bias for this family", the same footing as `fam`.

### Insights so far
1. **Constant g is not bounded at fam.** One vector per layer, tuned with targets, gains +0.09 macro on held-out items
   (3-fold +0.089, val +0.095), more than every fair centre so far (knnx8 +0.05, pco16 +0.04 on val strict). The card
   predicted +0.05 to +0.08 in-sample; the held-out gain is larger than that. -> S13 / S14 / S18 / S19b have something
   to find; the decode (next) says what kind of bias it is, which is the recipe for a label-free version (card S20b).
   **Qualified (B's cross-check, studies/S20x.md, 02:45):** `ceil.const - fam` promotes each family's *answer class*
   (multihop: Kepler / Einstein / Monet; DM: rowing / Jupiter / crochet; multilingual_mt: language names; multilingual:
   number words) and demotes template words and CJK function tokens. Its difference from fam lies outside fam's
   outlier coordinates and is orthogonal to fam (B, S18 insight 4): a new direction. Fit and val share 0 accepted forms on typo /
   association / DM, but 30 / 61 on multilingual, 24 on multilingual_mt (the language names), 16 / 42 on UM, 14 / 79 on
   multihop: there part of the val transfer is the same answers. So the headroom is (a) a target-category prior
   ("answers in this family are scientists / hobbies / language names") and (b) template demotion; (b) is fair from
   any label-free source, (a) needs a fair estimate of the answer class (B's S20x tests a leave-one-family-out one).
2. **h-dependence buys little except on DM.** Excluding DM, the best h-dependent class is within +0.02 of const on 3-fold
   (macro without DM: const 0.842, tok 0.824, clu 0.831, proj16 0.819). On DM, where read cells vary in token and
   position, tok / clu / proj16 reach 0.6-0.67 vs const 0.26: there the headroom needs a cell-specific g (as U1 / S8 found;
   whether it is fair is the mention-control question, not answered by a ceiling).
3. **multihop_mt is readout-limited** (card's prediction holds): every class 0.51-0.62 on val, in-sample 1.0 does not
   transfer; typo_mt likewise near fam on 3-fold.
