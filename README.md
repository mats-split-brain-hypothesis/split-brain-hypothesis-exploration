# Split-brain hypothesis: exploration

Code and notes from an exploratory MATS project on the "split-brain hypothesis": do models reward hack when they
believe they are in an evaluation or training, and follow the user's intent when they believe a real person is asking?

- `bianca/`: Bianca Ganescu's code, scenarios and notes (ImpossibleBench and School of Reward Hacks experiments).
  Start with `bianca/README.md` and `bianca/notes/`.
- Branches `bianca/*`: the latest state of each working branch, one per workstream. Each is a single snapshot
  commit; the history, run logs and transcripts are not included.
